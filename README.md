# Hydraulic Robotic Arm & CAM Manufacturing Project

A university engineering project focused on designing, manufacturing, and testing a Hydraulic Robotic Arm integrated with Machining & CAM (Computer-Aided Manufacturing) concepts.

The project demonstrates the application of fluid power systems, mechanical design, and manufacturing technologies in creating a functional robotic arm capable of performing basic pick-and-place operations.

---

## 📌 Project Overview

This project was developed as part of the Introduction to Manufacturing Technology module 

The robotic arm operates using a hydraulic actuation system powered by syringes and tubing instead of electrical motors. The system converts hydraulic pressure into mechanical motion, enabling the arm to:

- Grip lightweight objects
- Lift and move items
- Perform simple pick-and-place operations
- Demonstrate controlled motion using fluid mechanics

The project also included a Machining & CAM section involving manufacturing operations such as:
- Cutting
- Turning
- Drilling
- Threading
- CAM simulation and toolpath generation

# 🧪 Testing Results

The robotic arm was successfully tested and demonstrated:

✅ Smooth hydraulic movement  
✅ Stable structural performance  
✅ Successful object gripping  
✅ Effective force transmission through fluid pressure  

### Limitations
- Minor hydraulic leakage
- Slight response delay
- Need for higher dimensional precision

Despite these limitations, the project achieved its primary objectives successfully.
